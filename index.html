Welcome to the Challenge

This is an interactive Capture The Flag (CTF) challenge designed to teach you about Git and GitHub through exploration and problem-solving.

The flag is hidden across multiple locations in this repository—in commit messages, branches, files, and more. Your mission: find all four flag parts and assemble the complete flag.

What You'll Learn

  • Navigate Git history with `git log` and `git show`
  • Switch between branches and explore their contents
  • Decode and interpret commit messages
  • Use lateral thinking to find hidden information
  • Understand repository structure and metadata
🎮 Start Challenge 📖 Read Instructions

Challenge Format

  • Stage 1: Find flag part from a commit message (encoded)
  • Stage 2: Find flag part in a file across branch commits
  • Stage 3: Find flag part in a feature branch
  • Stage 4: Find the final piece

Tips

  • Use the browser console if you want—it's your CTF!
  • Each stage gives a hint when you click "Get Hint"
  • Hints are intentionally vague to keep the challenge engaging
  • Common Git commands: branch, log, show, checkout, diff
  • Think about encoding and hidden data structures
